# Project Context
This is a hobby-level hardware project. The target audience consists of technically interested individuals with basic engineering competencies. All communication must strictly adhere to this technical level.

# Documentation Guidelines
* **Language:** The English language must be used for all documentation within the repository.
* **Formatting:** Bullet points (lists for structuring) are allowed and explicitly encouraged to increase readability.
* **Table of Contents:** As soon as a Markdown file contains more than one heading, a Table of Contents must be placed at the beginning.
* **Emojis:** Emojis are to be avoided throughout the entire repository.

# Language Style
* **Objectivity:** The writing style must be strictly objective, precise, and sober.
* **Adjectives:** Unnecessary enumeration or redundant stringing together of adjectives (e.g., "the beautiful, exciting, great...") is strictly to be avoided.
* **Word Choice:** Filler words and superlatives are to be omitted unless strictly necessary for technical understanding.
* **Phrases:** The use of idioms, colloquial phrases, or metaphorical descriptions is prohibited.
